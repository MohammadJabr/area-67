# Earth elevation source comparison — Phase 2

Verification states are explicit: **LOCAL_QA** = local file acquired and structurally inspected; **REMOTE_WINDOW_QA** = official remote metadata and bounded window read; **CATALOG_VERIFIED** = exact item/extent/download record checked, but raster not read; **DOCUMENTED** = product/provider documentation only; **UNRESOLVED** = exact item or metadata question remains open. None of these labels certifies scientific suitability.

## Remote-read method and scientific limits

[`src/data/remote_cog_inspection.py`](../../../src/data/remote_cog_inspection.py) checks STAC assets, validates an HTTP range response and content lengths before GDAL sees the URL, caps requested windows, reads with rasterio `/vsicurl/`, and never writes raster files. HTTP range support succeeded for ArcticDEM, both REMA items, and the Iceland 10m GeoTIFF. Remote read metadata and window statistics are recorded in [`targeted_cog_access_2026-11-15.json`](../../../data/metadata/earth_dem_qa/remote/targeted_cog_access_2026-11-15.json). Previews are display-only.

Posting is not effective terrain resolution. Valid-cell coverage is not accuracy. Product surface types and acquisition histories differ. Vertical references also differ: Copernicus EGM2008, ArcticDEM/REMA ellipsoid, USGS NAVD88, and SRTM EGM96. No raw elevation comparison across these references was performed. ÍslandsDEM’s formal vertical CRS for the sampled TIFF remains unconfirmed from its raster tags/metadata association.
